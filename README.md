# Yuri House 3D

2026年6月26日付の住宅図面をもとに、建物の主要寸法と間取りを簡易的に立体化したブラウザビューアです。

## 使い方

- 「外観」「1階」「2階」で表示を切り替え
- 「斜め」「真上」「正面」で視点を切り替え
- ドラッグで回転
- ピンチまたはマウスホイールで拡大縮小
- 屋根・部屋名の表示切り替え

## 動作環境

外部ライブラリを使用しないHTML単体構成です。PCとiPhoneの主要ブラウザで利用できます。

## 注意

図面の主要寸法をもとにした簡易モデルです。家具、内装仕上げ、細部建具、設備位置などは実際の施工内容と異なる場合があります。
